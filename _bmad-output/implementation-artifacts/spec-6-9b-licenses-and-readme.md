## Intent

**Problem:** Репо ядра станет публичным, но MIT лежит только в `packages/core/LICENSE`, корневого
README нет, а README ядра не говорит, как поставить ядро в сайт. Ядро и демо несут чужие ассеты без
указанного происхождения. Набор иконок меню и callout — собственный, переработанный из разных
источников, но три иконки (`image`, `home` в callout, `document-placeholder`) сохранили узлы путей
Typicons (артворк под CC BY-SA 4.0); спрайт вьюера повторяет раскладку `default-skin.svg` PhotoSwipe 4
(MIT); у демо — шрифт Ubuntu (UFL 1.0).

**Approach:** Опознать каждый чужой ассет, записать его источник и лицензию в один файл уведомлений,
который едет и в npm-пакете, и держать полноту этого списка автоматической проверкой. Атрибуция живёт
только в этом файле: SVG, код и их комментарии не меняются. Положить MIT в корень, добавить короткий
корневой README и раздел установки в README ядра.

## Boundaries & Constraints

**Always:**

- Критерии 6.9: у каждого чужого ассета в ядре лицензия известна, совместима с MIT и указана в репо;
  ядро под MIT; README описывает установку ядра в сайт.
- Копирайт MIT — «the Astrum Scena authors», как в `packages/core/LICENSE`; имя владельца в текстах не
  появляется (AD-22, `pnpm check:identity`).
- Иконки меню и callout — собственный набор под MIT; `image`, callout `home` и
  `document-placeholder` записываются одной строкой «based on Typicons by Stephen Hutchings,
  CC BY-SA 4.0» (решение владельца). Остальные ассеты сверяются с названным кандидатом-источником;
  совпадение путей — запись с источником и лицензией, иначе ассет собственный.
- Атрибуция — только в файлах уведомлений и README: ни комментариев, ни заголовков в SVG и коде.
- Тексты README и уведомлений — на английском (AGENTS.md, Language).
- Полнота уведомлений — инвариант: проверка в `pnpm check` падает, если файл ассета ядра или шрифт
  демо не упомянут в уведомлениях.

**Never:**

- Не публиковать в npm, не создавать публичный репо, не убирать `--dry-run` и строку «Not published
  yet» (цель 3). Не коммитить.
- Не переписывать `docs/` и ADR на английский, не трогать `_bmad/` и `.claude/` кроме упоминания в
  уведомлениях.

## Implementation Notes

- Сверка: `social/telegram.svg` геометрически совпадает с `telegram` из `@mdi/svg@5.9.55` (в 6.x и
  7.x иконки нет), `social/github.svg` — с `github` из `@mdi/svg@7.4.47` (дуга переведена в кривые,
  округления другие); обе записаны как Material Design Icons, Apache-2.0, с полным текстом лицензии.
  `viewer-skin.svg` повторяет раскладку и часть глифов (лупы, полноэкранный режим, закрытие, стрелки)
  `default-skin.svg` PhotoSwipe 4.1.3 — MIT с копирайтом автора. `instagram`, `contacts`,
  `external-link` ни с чем не совпали — собственные.
- В `typicons.font@2.1.2` `LICENCE.md` прикладывает текст CC BY-SA 4.0; владелец согласовал 4.0 вместо
  ошибочной «3.0» из планирования (Intent и Always исправлены).
- `PUBLIC_HOSTS` пополнен `apache.org`, `creativecommons.org`, `dimsemenov.com` (URL из текстов
  лицензий).
- Блокер `check:identity`: строка копирайта PhotoSwipe (имя и фамилия автора) в
  `packages/core/THIRD_PARTY_NOTICES.md` попадает под запись денилиста владельца (имя). Решение
  владельца: строка `!<имя и фамилия автора PhotoSwipe>` в `.identity-denylist` и в секрете
  `IDENTITY_DENYLIST`; с ней гейт зелёный.
