# Метки PR

Две группы, различимые по цвету: холодные — что это за PR, тёплые — на что смотреть при мердже. У каждого
PR минимум одна метка типа и все подходящие метки риска; PR, которому не подходит ни один тип, означает
пробел в этих правилах — их нужно дополнить.

## Тип (холодные, минимум одна)

| Метка           | Цвет      | Когда                                                                            |
| --------------- | --------- | -------------------------------------------------------------------------------- |
| `feature`       | `#1F883D` | новая возможность или заметное улучшение для читателя или владельца              |
| `bug`           | `#8250DF` | исправляет ошибку, которую видели на живом сайте                                 |
| `documentation` | `#0969DA` | PR добавляет или меняет документацию                                             |
| `maintenance`   | `#0E7490` | инструменты, CI, рефакторинг, зависимости, хуки — без видимых читателю изменений |

Основной тип — один из `feature`, `bug`, `maintenance`; `documentation` добавляется к нему, когда PR несёт
документацию, и стоит одна, когда PR — только документация. Исправление ещё не вышедшего кода — не `bug`,
а тип той работы, которую оно доделывает.

Документация — документы для людей: `docs/` (гайды, how-to, runbook, ADR), README. Рабочие документы —
спеки и артефакты `_bmad-output/`, sprint-status, AGENTS.md, skills — документацией не считаются.

## Риск (тёплые, сколько подходит)

| Метка      | Цвет      | Когда                                                       |
| ---------- | --------- | ----------------------------------------------------------- |
| `deploy`   | `#B60205` | меняется деплой, секреты, R2, Cloudflare                    |
| `visual`   | `#F66A0A` | меняется внешний вид сайта или обновлены визуальные эталоны |
| `content`  | `#FBCA04` | меняется опубликованный текст в `src/content`               |
| `breaking` | `#6E0B0B` | ломает сайты на ядре; метку создать вместе с выносом ядра   |

Если риск под сомнением — метку ставить.
