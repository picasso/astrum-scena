# Backlog

Отложенные задачи: одна задача — один файл `bkNN-<slug>.md`. `bkNN` — стабильный ID: не меняется и
не переиспользуется, даже если задачу переименуют, сделают или отменят. Новая задача получает
следующий свободный номер; ссылаться лучше по ID.

Статусы: **отложено** — решение «не сейчас»; **условно** — нужна только при наступлении триггера;
**сделано** — с датой и ссылкой на коммит или PR, строка переносится в «Сделано».

Шаблон задачи: заголовок `BKNN. …`, строка **Статус**, разделы «Зачем», «Что сейчас», «Когда
вернуться», «Что сделать и что не входит», «Готово, когда».
