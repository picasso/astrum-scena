# BK11. Директива `:::links`: горизонтальная раскладка

**Статус:** отложено

## Зачем

Компактный ряд ссылок в строку вместо вертикального списка.

## Что сейчас

`:::links` рендерит только вертикальный `<ul>`, атрибут `layout` не вводится (тест
`src/lib/blocks/links/schema.test.ts`). Решение владельца: легаси-набор вертикальный, горизонтальный
ряд в контенте не нужен. План — `links-directive.md` в архиве планов (репо сайта).

## Когда вернуться

При реальной нужде в компактном ряду ссылок.

## Что сделать и что не входит

Enum `layout` с дефолтом `list` и вариант `inline`: тот же `<ul>` с `.links--inline`
(`display: flex; flex-wrap`), разделитель `·` или `•` через `::before`, зазор через `spacing`.
Изменение аддитивное. Не входит: смена поведения по умолчанию.

## Готово, когда

`layout=inline` даёт ряд с разделителями, список остаётся настоящим `<ul>`, существующий контент не
меняется.
