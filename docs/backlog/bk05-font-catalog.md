# BK05. Каталог шрифтов сайта

**Статус:** отложено

## Зачем

Выбирать семейство шрифта в site-config из предопределённого набора (до ~10), а не только Ubuntu.

## Что сейчас

Решение владельца зафиксировано в проходе по легаси-опциям темы (репо сайта):
дефолт — локальный Ubuntu, остальные — подгрузка с Google Fonts. Ключа в `site.yaml` и каталога нет.
Не путать с легаси `fonts_support` (per-page CSS в WordPress).

## Когда вернуться

Когда понадобится другой шрифт — на этом сайте или на следующем.

## Что сделать и что не входит

Ключ в схеме `site.yaml`, каталог семейств с весами и пайплайн загрузки (preload, `font-display`,
CSP для Google Fonts). Не входит: per-page шрифты.

## Готово, когда

Смена ключа меняет шрифт на всём сайте, Ubuntu остаётся локальным дефолтом, Lighthouse-бюджет не
просел.
