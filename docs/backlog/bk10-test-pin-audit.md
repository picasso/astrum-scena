# BK10. Аудит тестов на пин редактируемого контента и конфига

**Статус:** отложено

## Зачем

Тест, который сверяет точное редактируемое значение владельца, краснеет на легитимной правке
контента, а не на дефекте. Для `site.yaml` это уже запрещено в `AGENTS.md`.

## Что сейчас

Пин `navItems` в `ui.test.ts` заменён контрактами, E2E `navRoutes` выводится из `navItems` и
словарей. Остальные тесты не проверялись.

## Когда вернуться

Отдельный проход по тестам, при ближайшем test-hardening.

## Что сделать и что не входит

Пройти unit и E2E, найти пины наборов и порядка пунктов, значений `site.yaml`, текстов i18n,
editorial-picks и заменить контрактными проверками. Не входит: ADR-зафиксированные значения
(например ширины ADR-0008) — их пинить можно.

## Готово, когда

Правка редактируемого значения в пределах контракта не роняет ни один тест.
