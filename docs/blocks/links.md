# Links

- **Статус контракта:** согласован
- **Обновлено:** 2026-09-22
- **Общие правила:** [контентные блоки](README.md)

## Назначение

`Links` — статический «набор ссылок в конце материала»: вертикальный семантический `<ul>`, где одна
ссылка — один `<li>`. Блок заменяет прежний сырой inline-прогон с bold-лейблом
(`**ссылки:** [www.example.com](…) [www.example.org](…) …`) семантической контейнерной директивой. Он
рендерится без клиентского JS и без Astro-острова.

Блок чисто презентационный: у него НЕТ машиночитаемого поля (в отличие от [`Note`](note.md) с его
`claim`). Каждую ссылку блок прогоняет через общий [`resolveSafeLink`](../../src/lib/blocks/safe-link.ts)
(allowlist): внешние `http(s)` открываются в новой вкладке, внутренние относительные пути и фрагменты
`#anchor` — в той же, любая иная схема (`mailto:`, `tel:`, `javascript:`, `data:`, protocol-relative
`//host`) — ошибка сборки.

Блок не предназначен для:

- прозы, врезок и произвольного акцентного текста — для этого есть [`Callout`](callout.md);
- изображений, галерей и других контентных блоков;
- вложенных `Links`;
- горизонтальной раскладки — вариант `layout=inline` осознанно отложен
  ([BK11](../backlog/bk11-links-inline-layout.md)).

## Авторский контракт

Директива записывается в обычном `.md`/`.mdx`. Синтаксис тела СВОБОДНЫЙ: markdown-список НЕ обязателен —
блок сам собирает все ссылки в порядке следования и строит семантический `<ul>`. Достаточно просто
перечислить ссылки:

```md
:::links

[www.example.com](http://www.example.com)
[www.example.org](http://www.example.org)

:::
```

Эквивалентно работают и markdown-список (`-`/`*`), и несколько ссылок в одну строку:

```md
:::links

- [www.example.com](http://www.example.com)
- [www.example.org](http://www.example.org)

:::
```

Пример с несколькими атрибутами:

```md
:::links{title="Полезное" size="sm" gap="large" width="compact" align="left"}

- [www.example.net](http://www.example.net)
- [Фильтры](https://example.com/filters)
- [/ru/articles/filters/](/ru/articles/filters/)
  :::
```

### Атрибуты

Все атрибуты — закрытые enum-ы, fail-fast: неизвестный ключ/значение — ошибка сборки, тихого fallback
нет (как у `Callout`/`Note`).

| Параметр            | Значения                                       | Default       | Правило                                                                                                         |
| ------------------- | ---------------------------------------------- | ------------- | --------------------------------------------------------------------------------------------------------------- |
| `title` / `notitle` | строка / bare-флаг                             | локаль-дефолт | взаимоисключимы; `title` — непустая строка, рендерится как ЭКРАНИРОВАННЫЙ текст; `notitle` — только bare-флаг   |
| `size`              | `sm` · `base` · `lg`                           | `sm`          | размер шрифта ТОЛЬКО списка ссылок (заголовок не масштабирует) через CSS-токен                                  |
| `gap`               | `none` · `tiny` · `small` · `medium` · `large` | `tiny`        | вертикальный зазор между `<li>`; переиспользует ОБЩУЮ [шкалу расстояний](README.md#общая-шкала-расстояний)      |
| `width`             | `content` · `compact` · `full`                 | `content`     | `content` = shrink-wrap по самой широкой ссылке (с потолком), `compact` = ~60 % контейнера, `full` = вся ширина |
| `align`             | `left` · `center` · `right`                    | `right`       | блочное выравнивание при `width < full`; при `width=full` **молча игнорируется**                                |
| `icon`              | `none` · `each` · `heading`                    | `heading`     | МЕСТО декоративной иконки (глиф фиксирован по месту), не выбор глифа                                            |

### Заголовок и локаль

Заголовок в тело НЕ авторится — плагин печатает дефолт по локали документа:

| Локаль | Дефолтный заголовок |
| ------ | ------------------- |
| `ru`   | Ссылки              |
| `en`   | Links               |

Локаль определяется по имени файла (`…/x.ru.md(x)` → RU, `…/x.en.md(x)` → EN). Если локаль распознать
нельзя и явный `title` не задан — **ошибка сборки** с путём и позицией, а не молчаливый RU-дефолт.
Набор ссылок присутствует в обеих локалях и мигрируется симметрично, поэтому `:::links` ОСТАЁТСЯ в
structural-parity `/sync-mdx` (в отличие от пер-локального `note`).

## Допустимое содержимое

Контракт по СУТИ, а не по синтаксису: в теле — только ссылки. Блок собирает все `link` в порядке
следования из любой формы (markdown-список `-`/`*`, простые строки, несколько ссылок в строке,
упорядоченный список — всё сводится к одному `<ul>`).

- разрешено: inline-ссылки (безопасная схема, непустая подпись) в любом количестве и любой форме;
  внутри подписи — `strong`, `em`, `break`; пробелы и переносы между ссылками игнорируются;
- запрещено (ошибка сборки с путём и позицией): любая непробельная проза рядом со ссылками, заголовки,
  изображения, таблицы, кодовые блоки, raw HTML, reference-style ссылки, вложенные директивы/MDX,
  вложенный `:::links`, task-list чекбоксы (`- [ ] …`), ссылка с пустой/только-форматирующей подписью;
- пустое/пробельное тело (ни одной ссылки) — ошибка сборки.

## Преобразование Markdown в HTML

Плагин ([`plugin.ts`](../../src/lib/blocks/links/plugin.ts)) ловит `containerDirective` с именем
`links`, строго валидирует атрибуты и поддерево, аннотирует ссылки через `resolveSafeLink` и заменяет
узел статическим `<div>`:

```html
<div class="links links--sm links--gap-large links--w-compact links--left links--icon-heading">
	<p class="links__title">
		<span class="links__icon" aria-hidden="true"><!-- inline bookmark SVG --></span>
		Полезное
	</p>
	<ul class="links__list">
		<li>
			<a href="http://www.example.net" target="_blank" rel="noopener noreferrer"
				>www.example.net</a
			>
		</li>
		<li>
			<a href="https://example.com/filters" target="_blank" rel="noopener noreferrer"
				>Фильтры</a
			>
		</li>
		<li><a href="/ru/articles/filters/">…</a></li>
	</ul>
</div>
```

- Носитель — обычный `<div>` (не landmark): 1–2 хвостовых набора ссылок на статью не стоят отдельного
  `<nav>`-landmark'а (та же логика, что у `role="note"` вместо `<aside>`).
- Заголовок — chrome-строка `<p class="links__title">`, а не настоящий `<h*>`, чтобы не засорять
  document outline.
- Иконки декоративны (`aria-hidden="true"`), доверенные статические SVG; текст заголовка — mdast
  `text`-узел, поэтому hast-сериализатор сам экранирует значение (враждебный `title` не инъектирует
  разметку).
- При `notitle` весь `<p class="links__title">` (вместе с иконкой) не выводится.

### Иконки и маркеры пунктов

`icon` управляет только МЕСТОМ декоративной иконки; глиф фиксирован по месту. Маркер пункта и per-link
иконка взаимоисключимы:

- `heading` (дефолт) — `bookmark` у заголовка; перед каждой ссылкой стоит **полый буллет** (`circle`).
  Иконка заголовка рендерится ТОЛЬКО когда рендерится заголовок; при `notitle` она молча не выводится
  (буллеты остаются).
- `each` — ↗ (`external-link`) **ведущим** маркером (перед текстом) у КАЖДОЙ внешней ссылки; буллет при
  этом НЕ выводится — ролью маркера служит сам ↗. Внутренние ссылки остаются без ↗ и без буллета.
- `none` — без иконок, но с полыми буллетами (как `heading`).

Глиф `bookmark` взят из одобренного набора темы `zu` (`sources/_minified/icons`), ↗ — из
предоставленного владельцем [`src/assets/icons/external-link.svg`](../../src/assets/icons/external-link.svg);
[`icons.ts`](../../src/lib/blocks/links/icons.ts) держит нормализованные встроенные копии. ↗ декоративна
и не озвучивает «открывается в новой вкладке» — это совпадает с текущей конвенцией сайта для внешних
ссылок.

## Размеры, ширина, зазор и контраст

Собственные числовые токены блока — только `size` и `width-compact`
([`tokens.ts`](../../src/lib/blocks/links/tokens.ts)); зазор берётся из ОБЩЕЙ шкалы `--content-gap-*`, а
цвет ссылок — из легаси прозовых токенов темы (`--color-link`). Поэтому у блока нет собственной пары
«текст на заливке» — WCAG-контраст держит тема (как у line/transparent-вариантов `Callout` и всего
`Note`).

Ссылки по умолчанию НЕ подчёркнуты: пунктирное (`dashed`) подчёркивание появляется на `:hover` и
`:focus-visible` (клавиатурная доступность). Постоянное подчёркивание опущено осознанно — весь блок
состоит из ссылок в списке, поэтому двусмысленности «ссылка это или текст» нет (как в навигации), а
disc-буллет / ведущий ↗ дополнительно маркируют каждый пункт. Раскладка списка — блочная (не flex):
`display:flex` блокифицировал бы `<li>` и убрал бы `::marker`, поэтому зазор задаётся
`margin-block-start` на `li + li`. `size` масштабирует ТОЛЬКО список (`.links__list`), заголовок всегда
прозового размера. Список получает небольшой левый отступ (`margin-inline-start: 1em`), чтобы визуально
быть «вдвинутым» относительно заголовка. Длинные URL-подписи переносятся
(`overflow-wrap`/`word-break`), чтобы одна длинная ссылка не распёрла контейнер.

Значения зеркалятся в CSS-переменные в [`links.css`](../../src/styles/blocks/links.css); drift TS↔CSS,
привязку зазора к общей шкале и молчаливое обнуление `align` при `width=full` ловит
[`tokens.test.ts`](../../src/lib/blocks/links/tokens.test.ts).

## Валидация

Схема ([`schema.ts`](../../src/lib/blocks/links/schema.ts)) и сборщик ссылок
([`validate-children.ts`](../../src/lib/blocks/links/validate-children.ts)) работают fail-fast:
неизвестный параметр/значение, `.class`/`#id`, `notitle` со значением, `title` вместе с `notitle`,
непробельная проза рядом со ссылками, запрещённый узел, пустая подпись, небезопасная схема ссылки или
пустое тело — ошибка сборки с путём и позицией. Рендер идентичен в `.md` и `.mdx` (общий
mdast-конвейер Sätteri).
