# Note

- **Обновлено:** 2026-09-10
- **Общие правила:** [контентные блоки](README.md)

## Назначение

`Note` — статическое errata-примечание «что изменилось с момента написания». Это управляемый блок
поправок ([ADR-0011](../adr/0011-content-errata.md)): к статье, написанной 10+ лет назад,
`/factcheck-apply` добавляет короткие авторские аннотации о том, что устарело (снятый с производства
продукт, переименованная компания, изменившийся факт). Каждая нота самодостаточна и несёт
машиночитаемый идентификатор находки фактчека.

Блок заменяет прежний механизм на HTML-комментариях (`<!-- errata:begin/end -->` + `<!-- note:… -->`)
семантической контейнерной директивой. Он рендерится в статический `<div role="note">` в амбер-тоне
«устарело», без клиентского JS и без Astro-острова.

Блок не предназначен для:

- цитат, врезок и произвольного акцентного текста — для этого есть [`Callout`](callout.md);
- изображений, галерей и других контентных блоков;
- вложенных `Note`;
- интерактивного поведения на клиенте.

## Авторский контракт

Директива записывается в обычном `.md`/`.mdx`:

```md
:::note{claim="prod-d602206b:64cf2f9d"}
Шаровую голову Acratech V2 больше не выпускают — её место заняли модели GP и GXP.
:::
```

Вторая и последующие ноты в одной группе печатаются с bare-флагом `notitle`, чтобы заголовок
«Что изменилось с момента написания» не повторялся:

```md
:::note{claim="prod-6d974afa:6a529658" notitle}
Штативы Gitzo серии «G» сняты с производства — им на смену пришли Systematic и Mountaineer.
:::
```

### Атрибуты

| Параметр  | Default        | Правило валидации                                                                             |
| --------- | -------------- | --------------------------------------------------------------------------------------------- |
| `claim`   | — (обязателен) | `findingId:digest8`; `findingId` из `[A-Za-z0-9._-]` (без двоеточия), `digest8` — 8 hex lower |
| `title`   | локаль-дефолт  | Непустая строка; взаимоисключим с `notitle`; рендерится как ЭКРАНИРОВАННЫЙ текст, не raw HTML |
| `notitle` | `false`        | Только bare-флаг (`notitle`); `notitle="true"` — ошибка сборки                                |
| `tone`    | `'outdated'`   | `outdated` (амбер) · `info` (голубой) · `alert` (красный); неизвестное — ошибка сборки        |
| `icon`    | `'history'`    | Значение из закрытого набора; неизвестное — ошибка сборки                                     |

`claim` ОБЯЗАТЕЛЕН (в отличие от всех опциональных атрибутов `Callout`): нота без него не
машиночитаема, поэтому её отсутствие — ошибка сборки. `claim` — единственное машинное поле; формат
задаёт [`src/lib/blocks/note/claim.ts`](../../src/lib/blocks/note/claim.ts), общий и для рендера, и
для контентной errata-машинерии.

### Заголовок и локаль

Заголовок в тело НЕ авторится — плагин печатает дефолт по локали документа:

| Локаль | Дефолтный заголовок                     |
| ------ | --------------------------------------- |
| `ru`   | Что изменилось с момента написания      |
| `en`   | What has changed since this was written |

Локаль определяется по имени файла (`…/x.ru.md(x)` → RU, `…/x.en.md(x)` → EN). Если локаль
распознать нельзя и явный `title` не задан — **ошибка сборки** с путём и позицией, а не молчаливый
RU-дефолт (иначе в EN-документе напечатался бы русский заголовок). RU/EN-директивы структурно
идентичны, поэтому `/sync-mdx` исключает `note` из structural-parity, а `/factcheck-apply` управляет
errata пер-локально.

## Допустимое содержимое

Тот же узкий whitelist, что у [`Callout`](callout.md):

- разрешены: непустые абзацы, inline-ссылки (безопасная схема), `strong`, `em`, упорядоченные и
  неупорядоченные списки, переносы строк;
- запрещены: заголовки, изображения, таблицы, кодовые блоки, raw HTML, reference-style ссылки,
  вложенные директивы/MDX, вложенный `:::note`;
- пустое/пробельное тело — ошибка сборки.

## Преобразование Markdown в HTML

Плагин ([`plugin.ts`](../../src/lib/blocks/note/plugin.ts)) ловит `containerDirective` с именем
`note`, строго валидирует атрибуты и поддерево и заменяет узел статическим `<div>`:

```html
<div class="note note--outdated" role="note">
	<p class="note__title">
		<span class="note__icon" aria-hidden="true"><!-- inline history SVG --></span>
		Что изменилось с момента написания
	</p>
	<div class="note__content">
		<p>Шаровую голову Acratech V2 больше не выпускают …</p>
	</div>
</div>
```

- `role="note"` (а не `<aside>`): errata-аннотация не должна засорять landmark-карту статьи 4–5
  дополнительными `complementary`-областями.
- Заголовок — chrome-строка `<p class="note__title">`, а не настоящий `<h*>`: несколько одинаковых
  заголовков не должны попадать в document outline.
- Иконка декоративна (`aria-hidden="true"`), доверенный статический SVG; текст заголовка — mdast
  `text`-узел, поэтому hast-сериализатор сам экранирует значение (враждебный `title` не может
  инъектировать разметку).
- При `notitle` весь `<p class="note__title">` (вместе с иконкой) не выводится.

## Тон и контраст

Тона (закрытый enum): `outdated` (амбер «устарело»), `info` (голубой), `alert` (красный). Блок
рендерится как ТИНТ: заливка тона накладывается с прозрачностью (`--note-tint`, дефолт 20 %) на фон
страницы, заголовок берёт яркий `fill` тона, а текст — производный от `fill` цвет (тёплый/холодный
белый в тёмной теме, тёмный в светлой) с собственной прозрачностью. Поэтому у блока нет пары «сплошной
текст на сплошной заливке» — контраст обеспечивает тема (как у line/transparent-вариантов Callout).

Значения тонов живут в [`tokens.ts`](../../src/lib/blocks/note/tokens.ts) (`fill` — яркий цвет тона,
`border` — приглушённее для левого бара и иконки) и зеркалятся в CSS-переменные `--note-<tone>-*`
([`note.css`](../../src/styles/blocks/note.css)); drift ловит
[`tokens.test.ts`](../../src/lib/blocks/note/tokens.test.ts). Ссылки внутри ноты — сплошное
подчёркивание `1px`/offset `2px`, различимы без опоры на цвет.

Новый тон добавляется в трёх согласованных точках: значение в `NOTE_TONES`
([`schema.ts`](../../src/lib/blocks/note/schema.ts)), пара токенов в `tokens.ts` + `note.css`
(`--note-<tone>-{fill,border}` и правило `.note--<tone>`), строка зеркала в `tokens.test.ts`.

> **OWNER CHECKPOINT.** Иконка `history` в [`icons.ts`](../../src/lib/blocks/note/icons.ts) —
> временная заглушка. Одобренный источник иконок сайта — `zu/sources/_minified/icons`; замените
> значение на утверждённый SVG из него.

## Валидация

Схема ([`schema.ts`](../../src/lib/blocks/note/schema.ts)) и валидатор детей
([`validate-children.ts`](../../src/lib/blocks/note/validate-children.ts)) работают fail-fast:
неизвестный параметр/значение, `.class`/`#id`, `notitle` со значением, `title` вместе с `notitle`,
отсутствующий/малформ `claim`, запрещённый ребёнок или пустое тело — ошибка сборки с путём и
позицией. Рендер идентичен в `.md` и `.mdx` (общий mdast-конвейер Sätteri).

## Связь с errata-машинерией

Управляемый errata-регион — хвостовой прогон `:::note{claim="…"}`-директив в конце RU-тела рабочего
документа. Регион может стоять и до, и после завершающих `:::links`-блоков — порядок выбирает автор
по вкусу; правка, удаление и вырезка для digest свежести оставляют `:::links` на месте, новый регион
вставляется перед ними. Его разбор/сериализация (fail-closed, канон-якорный, версия-независимый) живут в
[`errata-edit.ts`](../../src/lib/content/errata-edit.ts) и используют общий формат `claim` из блока.
Дискриминатор — наличие `claim`; он ОБЯЗАТЕЛЕН. Презентационные `tone`/`icon` машинерии безразличны —
она их терпит и сохраняет при round-trip (автор владеет оформлением), `notitle` остаётся позиционным.
Неизвестный атрибут или `title` на claim-ноте — fail-closed. Нота без `claim` (ручная/декоративная)
машинерией не управляется.
