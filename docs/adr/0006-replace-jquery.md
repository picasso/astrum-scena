# ADR-0006: Замена jQuery — native-first + Motion One

- **Статус:** accepted
- **Дата:** 2026-07-18

## Контекст

На текущем сайте интерактив (фейды, появление при скролле, плавный скролл, hero-слайдер,
лайтбокс) построен на **jQuery** и наборе jQuery-плагинов. При переезде jQuery в новый стек
не тащим — это legacy-вес, противоречащий zero-JS-дефолту Astro и цели долговечности.

## Решение

**Native-first**, крошечная современная либа только там, где нативно неудобно, jQuery — нигде.
Каждая анимация — либо чистый CSS в `.astro` (ноль JS в браузер), либо маленький остров.

| Поведение                                    | Замена                                                                                                 |
| -------------------------------------------- | ------------------------------------------------------------------------------------------------------ |
| Фейды / появление при скролле                | `IntersectionObserver` + CSS transitions/`@keyframes` (или scroll-driven `animation-timeline: view()`) |
| Плавный скролл / якоря                       | CSS `scroll-behavior: smooth` + нативный `scrollIntoView`                                              |
| Hero-слайдер                                 | **Swiper** (без jQuery)                                                                                |
| Лайтбокс                                     | **PhotoSwipe v5** (без jQuery)                                                                         |
| Гамбургер-меню, тогглы                       | vanilla TS в острове + CSS-переходы                                                                    |
| Ховеры                                       | чистый CSS                                                                                             |
| Сложная секвенированная анимация / параллакс | **Motion One** (~5 КБ, Web Animations API) — только если нативно громоздко                             |

## Альтернативы

- **Тащить jQuery** — отвергнуто: legacy-вес, против zero-JS и долговечности.
- **GSAP** — мощно, но тяжелее и с нюансами лицензии; избыточно для фотосайта.
- **Только нативка, без либ** — рабочий минимум; Motion One оставлен как точечный инструмент
  для редких сложных секвенций, чтобы не изобретать WAAPI-обвязку руками.

## Последствия

- (+) Сохраняется zero-JS-дефолт: анимации — CSS в `.astro` или маленькие острова.
- (+) Долговечно: минимум зависимостей, нативные API.
- (+) Две главные вещи (слайдер, лайтбокс) уже покрыты Swiper/PhotoSwipe без jQuery.
- (−) Требуется аудит старых скриптов (что оставляем/убираем) — вынесен в роадмап (S2).
